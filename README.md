# NubilynQ2 (ヌビリンク2) - Releases

ここは記念日・ギフト履歴管理アプリ「NubilynQ2」のAndroid版（APK）を配布する公式リポジトリです。
本リポジトリにはソースコードは含まれず、アプリのリリース版（APKファイル）および更新履歴のみを提供します。

## 📥 ダウンロードとインストール

最新のAPKファイルは、当リポジトリの **[Releases](../../releases)** ページからダウンロードできます。

1. **Releases** ページを開き、最新のバージョン（例：`v1.2.1`）を確認します。
2. **Assets** セクションから `NubilynQ2-x.x.x-arm64.apk` をダウンロードします。
3. Android端末でダウンロードしたファイルを開き、インストールを実行します。
   ※初めてインストールする場合、「提供元不明のアプリのインストール」を許可する設定が必要です。

## 📱 動作環境

* **対応OS**: Android 9.0 以降
* **対応アーキテクチャ**: `arm64-v8a` (最近の一般的なAndroidスマートフォン)

## 🔒 プライバシーとセキュリティ

NubilynQ2は、ユーザーのプライバシーを最優先に設計された完全プライベートなアプリです。
アプリ内のデータはすべてお使いの端末内にのみ保存され、開発者や外部のサーバーへ勝手に送信されることはありません。
（クラウドバックアップ機能を利用する場合のみ、ご自身のGoogle Driveの安全な領域に暗号化された上で保存されます）

* **プライバシーポリシー**: [カレンラボのプライバシーポリシーページへ](https://note.curren-lumi.blog/nubilynq2-privacy-policy/)
